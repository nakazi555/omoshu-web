# 熊本ナイト（仮）企画書

作成日: 2026-08-02
作成: 中島
共有先: 宮澤
参考資料: [アイデア一覧とリサーチ](./kumamoto-ideas.md)

> この企画で、番組側の収益はゼロです。
> 集まったお金は全額、熊本県の公式義援金口座に届きます。

---

## 1. 趣旨

**東京から、熊本のことを言い続ける。**

自分たちが集められる金額は、正直に言えば大きくない。番組の規模はエピソード23本、直近10話の再生を合計しても12,311回。NPOや芸能人と金額で競っても意味がない。

ただ、災害支援でいちばん失われるのは金ではなく**関心**だと分かっている。2016年の熊本地震では、直接壊れた被害よりも「行かなくなる・買わなくなる」被害のほうが大きかった。九州全体で宿泊キャンセルは75万人。2016年5月の宿泊者数は、直接被害の小さかった大分で-39.4%、長崎で-30.7%。むしろ熊本本体は-10.6%にとどまっている。

**忘れられることが、いちばんの被害だった。**

自分たちが持っているのは、毎週配信という定期接触装置と、元KKTアナウンサーの声と、AIで仕組みを作る手だ。これは「大金を一度集める」には向いていないが、「言い続ける」には向いている。

だから、この企画のゴールは金額ではない。

- 熊本のことを話す場を、**続く形で**作る
- 東京にいる熊本ゆかりの人と店を、**つながった状態にして残す**
- その結果として、義援金を届ける

---

## 2. 企画の芯：一方通行にしない

宮澤の案をそのまま中心に据える。

```
東京にある熊本ゆかりの店・企業が協賛する
        ↓
宮澤が読み上げ・宣伝で返す（音声データを納品）
        ↓
協賛金は熊本県の義援金口座へ
        ↓
熊本の人が東京に来たとき、その店を使う
        ↓
（翌年へ）
```

**これは「支援」ではなく「縁」の形をしている。** ここが他のチャリティと決定的に違う。

そして、単発の読み上げで終わらせない。協賛してくれた店を **「熊本ゆかり店マップ（東京）」** として、番組サイト上に恒常公開の資産として残す。

これが効く理由は4つ:

1. **協賛の対価が消えない** → 翌年も協賛してもらう理由になる
2. **熊本の人が東京に来たときの実用ツールになる** → 施しではなく、使えるものになる
3. **2016年の教訓への直接の答えになる** → 「行かなくなる・買わなくなる」の逆流を作る
4. **不謹慎批判に対する最も強い盾になる** → これは飲み会ではなく、経済を回す活動である、という事実が形として残る

※ サイトへの実装は、この企画書に宮澤の合意が出てから着手する。

## 3. 時期：9月以降を推奨（最重要）

**急性期にはやらない。** 現時点（8月2日）は、避難者9,800人超、車中泊1,000人超、猛暑下の熱中症対策が急務という段階。熊本市が物資集積センターを立ち上げたのが8月1日。まだ現地が動いている最中で、東京で会をやる時期ではない。

推奨は**9月以降**。そしてこの遅らせ方を、企画の言い訳ではなく**主張そのもの**にする。

> 「支援がいちばん細るのは、みんなが忘れ始める頃です。だから、その頃にやります。」

これは時期への批判に対して反論のしようがない。しかも企画の存在理由（＝風化に抗う）と完全に一致している。**遅いのではなく、狙って遅らせている。**

なお熊本県の義援金受付は10月30日まで。9月開催なら十分に間に合う。

## 4. 見え方の設計

### 前提として共有しておきたいこと

宮澤が気にしていた件、記憶より深刻で、しかも**5日前の現在進行形の話**でした。

2026年7月28日、熊本の震度7の発生から約1時間半後の18時から、自民党福岡県議団の松尾統章会長が北九州市内のホテルで政治資金パーティーを開催。チケットには「ビアパーティ」、会費1万5千円・アルコールを含む飲食付き、お笑い芸人の余興付き、500人以上が参加。7月30日に報道され、「正直やってよかった」という発言も含めて批判を浴びています。服部誠太郎・福岡県知事も「こういう時に飲食を伴う会合を開くことは不適切ではないか」と発言。県連内部からも「お笑い芸人が余興として出演する必要があったのか」という声が出ている状況です。

**つまり、今この論点に対する世間の目は最も厳しい。**

一方で、逆側の事実もあります。2016年の熊本地震では「不謹慎狩り」が社会問題化し、企業の広告自粛や無関係なイベントの中止が連鎖した結果、**過剰な自粛がむしろ復興を妨げた**と総括されています。

だから結論は「やらない」ではなく、**「誤読されようがない形にする」**です。

### 松尾氏の件を分解すると、叩かれた理由は7つある

| 叩かれた要素 | この企画での裏返し |
|---|---|
| 目的が自分の資金集めだった | 目的が支援。**番組側の収益はゼロ** |
| 名称が「ビアパーティ」だった | 告知の一行目に目的を置く。宴会に読める名前を使わない |
| 会費1万5千円が主催者に入った | **主催者は1円も受け取らない**（§5参照） |
| お笑い芸人の余興＝娯楽が主目的に見えた | 構成の主役は熊本の話。番組らしさは中盤以降 |
| 発災当日・1時間半後だった | 9月以降。時期そのものを主張にする（§3） |
| 事後に釈明した（順序が逆） | **事前に**趣旨と金の流れを公開、**事後に**総額と振込控えを公開 |
| 当事者が中にいなかった | 宮澤（家族が被災）、熊本ゆかりのゲスト、熊本ゆかりの店が主体 |

「時期」は7つのうちの1つでしかない。時期をずらすだけでは足りず、残り6つを設計で潰す。

### 運用チェックリスト（告知前に全部確認する）

- [ ] 告知の第一行は「目的」と「金の行き先」。イベント名より先に置く
- [ ] 「パーティー」「飲み放題」など、宴会に読める語を告知文に使わない
- [ ] 乾杯の写真をトップに置かない。告知・報告の主役は金額と行き先
- [ ] 番組側の収益がゼロであることを明記する
- [ ] 当事者（宮澤・熊本ゆかりのゲスト・熊本ゆかりの店）が主体だと分かる書き方にする
- [ ] 開催**前**に、趣旨と金の流れを公開する
- [ ] 開催**後**に、総額と振込控えを公開する（この順序は絶対に逆にしない）
- [ ] 批判が来たときの想定問答を1枚、事前に用意しておく

> 補足: 「過剰な自粛は復興を妨げる」という論は、**判断根拠として内部で持つのはいいが、対外的には主張しない**。言えば言い訳に見える。実績で示すほうが強い。

## 5. お金の設計（ここが一番大事）

### 問題

参加費に飲食の原価が混ざると、「全額寄付」と言えなくなる。ここが曖昧なまま告知すると、それだけで叩かれる。

### 推奨案：主催者はお金を触らない

| 種別 | 誰が払う | どこへ流れる | 主催者の関与 |
|---|---|---|---|
| 参加費 | 参加者 | 会場（飲食実費のみ） | 立て替えのみ。利益ゼロ |
| 個人の寄付 | 参加者 | **その場でQRから熊本県口座へ各自が直接振込** | **なし（お金を触らない）** |
| 法人・店の協賛 | 協賛店・企業 | 主催者がいったん受け取り、一括で熊本県口座へ | 受領と振込。控えを公開 |

**個人の寄付は主催者を経由させない。** 当日、熊本県の義援金口座のQRコードを配って、その場で各自のスマホから振り込んでもらう。総額は自己申告で集計して、その場で発表する。

これの何がいいか:

- 会計リスク・税務リスクがゼロになる
- 「集めたお金はどうなるの？」という質問に一言で答えられる（「僕らは触りません」）
- 「主催者が中抜きしているのでは」という疑いが構造的に発生しない
- **募金箱を回すより、その場で全員が振り込む光景のほうが強い**

法人協賛だけは、請求と領収の都合上こちらで受け取らざるを得ない。ここは振込控えを公開して透明性を担保する。

### 比較：主催者が全額集めて振り込む方式

| | 主催者が触らない案（推奨） | 主催者が全額集める案 |
|---|---|---|
| 会計・税務リスク | なし | あり（専用口座が要る） |
| 説明のしやすさ | 一言で済む | 説明が必要 |
| 総額の正確さ | 自己申告なので誤差が出る | 正確 |
| 「集めた」実感 | やや薄い | 強い |
| 手間 | 小 | 大 |

**推奨は前者。** ただし宮澤が「総額をきっちり出して発表したい」と考えるなら後者もあり得るので、判断を委ねたい。

## 6. 第一弾「熊本ナイト vol.1」

### 概要

| 項目 | 内容 |
|---|---|
| 時期 | 2026年9月以降（§3） |
| 会場 | とこなつ家 or シスイドゥ（どちらも協力してくれそう） |
| 定員 | 30〜50人。**小さく確実に** |
| 参加費 | 飲食実費のみ（会場と相談して確定） |
| 寄付 | 参加費とは別建て。当日その場で各自が熊本県口座へ |
| 主催 | オモシュワ（宮澤・中島） |

定員を絞るのは意図的。50人で満席にして「次は入れなかった」と言われる状態を作るほうが、100人枠を半分埋めるより vol.2 につながる。

### 当日の構成

| 順 | 内容 | 狙い |
|---|---|---|
| 1 | 宮澤の「あの日」 — 妻子が熊本にいた話 | **一次体験から始める。** ここが同情の会ではなく当事者の会だと決まる瞬間 |
| 2 | 熊本ゆかりゲストのトーク | 候補: 中道さん（八代出身）、富田宇宙さん、まきさん |
| 3 | 協賛店の紹介を宮澤が生アナウンス | 協賛リターンの本番。ここは完全にプロの仕事として見せる |
| 4 | **参加者から集めた「熊本の思い出」の朗読** | **この企画の芯**（下記） |
| 5 | 寄付タイム（QRで各自振込）＋ 総額発表 | 全員が同時に振り込む光景を作る |
| 6 | vol.2 の日付告知 | ここを飛ばすと単発で終わる |

熊本の食材・酒を出せるなら出す。取り寄せること自体が経済支援になる。

### ④が企画の芯

**事前に参加者・リスナーから「熊本の思い出」をテキストで募る → AIで一本の朗読原稿に構成する → 元アナウンサーの宮澤が読む。**

この3点セットは、他の誰にもできない。

- テキストを集める部分 → 番組のリスナーとLINE BOT（オモシュワくん）がある
- 構成する部分 → AIがないと、100通のバラバラな思い出を一本にまとめるのは無理
- 読む部分 → 元KKTアナウンサーの声

これは「AIに勝てる、くだらなさを探せ」という番組コンセプトの、裏返しの回答にもなっている。**AIが集めて構成したものを、人間の声が最後に届ける。**

## 7. 協賛メニュー（熊本コール）

宮澤のアナウンス音声を返礼にする。原価はほぼゼロなのに、普通は金で買えない。**この非対称性が全て。**

| 枠 | 想定 | 内容（案） |
|---|---|---|
| 個人 | 小口 | 名前＋熊本への一言を、宮澤が番組内でコール。音源データを納品 |
| 個人スペシャル | 中口 | 30秒のパーソナル音源（誕生日メッセージなど）。用途自由 |
| 店・法人 | 大口 | **60秒のCMナレーション**（原稿もこちらで用意）＋ 当日会場での生アナウンス ＋ 番組内クレジット ＋ **店マップ掲載** |
| 冠 | 最大 | 上記すべて＋番組ゲスト出演枠 or 冠コーナー |

金額は宮澤と相談して決める。

**納品する音源は用途自由**にする。店内BGM、SNS、電話の保留音、ホームページ。使われるほど「熊本のために協賛した店」という事実が街に残る。

## 8. AIの使いどころ（中島の担当）

「AIが使える」を実効のあるものにする部分。ここが機能しないと、協賛が10件を超えた時点で破綻する。

1. **協賛者情報 → ナレーション原稿の自動生成** — 宮澤は読むだけの状態にする。**100件でも回る**
2. **音源の命名・書き出し・配布リンクの自動化** — 納品作業を人力でやらない
3. **参加者の思い出テキスト → 朗読原稿への構成**（§6の④）
4. **告知素材の量産** — ショート、バナー。番組の既存フローに乗せる
5. **店マップ／100人名鑑の下調べ・質問設計・書き起こし・記事化**

宮澤にお願いしたいのは、**声を出すことだけ**にしたい。原稿づくり・編集・納品・告知はこちらで全部持つ。

## 10. やらないこと

明記しておく。これも企画の一部。

- **個人からの物資送付の呼びかけはしない** — 熊本市は8月1日から物資集積センターを稼働させ、避難所ごとのニーズに応じて配分する体制に入っている。個人からのバラバラな発送は現場の負担になる
- **現地ボランティアの募集はしない** — 受け入れ体制次第。自分たちが判断できる情報を持っていない
- **AIを使った情報支援システムのようなものは作らない** — 一見いちばん「自分たちらしい」が、現地のニーズの一次情報を持たないままやると善意が邪魔になる
- **番組のくだらなさを捨てない** — ただし当日の構成順（重い話から始めて、後半で番組らしさを出す）で担保する。全編を湿っぽくはしない
- **「元KKTアナウンサー」という肩書きの使い方は宮澤の判断に委ねる** — 古巣との関係もあるので、告知にどう書くかは決めてほしい

## 補足：この企画が失敗するとしたら

正直に書いておく。

- **単発で終わる** — アイスバケツチャレンジは1ヶ月で1億1,500万ドルを集めたが、寄付者のリピート率は1%未満だった。一方Games Done Quickは初回$52,000から始めて、年2回の定期開催を続けた結果、累計$59M超になった。**vol.1の当日にvol.2の日付を告知するかどうかが分岐点**
- **人が集まらない** — 番組の動員力だけでは足りない。東京熊本県人会・TOKYO BASE 096への一報と、ゲスト経由の集客が要る
- **見え方で炎上する** — §4のチェックリストを1つでも飛ばすとリスクが上がる
- **番組の月1コーナー「熊本の今」を作らない** — イベントより地味だが、**費用対効果はこちらのほうが上**。これをやらないなら、この企画は一発で終わる
