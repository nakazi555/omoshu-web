## 1. 前提：いま何が起きているか

### 令和8年熊本地震
- 2026年7月28日 16時27分頃、熊本県熊本地方でM7.1、最大震度7（宇城市・氷川町）。震源の深さ約10km。津波のおそれも発表された
- 避難者は9,800人超。うち車中泊が1,000人超とみられる
- 猛暑下のため、避難所の熱中症対策（空調・電源車）が急務になっている
- 熊本市は8月1日に物資集積センターの運用を開始。避難所ごとのニーズに応じて配分する体制に入った
- くまモンが活動休止（2016年に続き2回目）

## 2. 「見え方」に関する事実 ← 企画の必須要件

### 直近の事例：発災当日のパーティー
2026年7月28日、震度7の発生から約1時間半後の18時から、自民党福岡県議団の松尾統章会長が北九州市内のホテルで政治資金パーティーを開催した。

- チケットには「ビアパーティ」と記載
- 会費1万5千円、アルコールを含む飲食付き
- お笑い芸人による余興あり
- 500人以上が参加
- 7月30日に報道。松尾氏は「当時、地震の情報がほとんどなく、中止の判断ができる状況ではなかった」と釈明。それ以前には「正直やってよかった」とも発言
- 服部誠太郎・福岡県知事は「こういう時に飲食を伴う会合を開くことは不適切ではないか」と批判
- 県連内部からも「県議団の会長として中止にすべきだった」「お笑い芸人が余興として出演する必要があったのか」との声

**これは5日前の、現在進行形の話。** 世間の目が最も厳しいタイミングにいるという前提で設計する必要がある。

### 逆側の教訓：不謹慎狩り（2016年）
2016年の熊本地震のあと、「不謹慎狩り」が一夜で流行語になった。

- ゲーム機の購入報告や、友人との食事の写真が「熊本の人が苦しんでいるのに」と叩かれた
- 著名人の寄付が「偽善」と攻撃された
- 企業が広告を自粛し、地震と無関係なイベントまで中止が連鎖した
- 結果として**全国の経済活動が縮み、復興をむしろ妨げた**と総括されている

### 結論：「やらない」は正解ではない。「誤読されようがない形にする」が正解

松尾氏の件が叩かれた理由を分解すると、「時期」は7要素のうちの1つでしかない。

| 叩かれた要素 | この企画での裏返し |
|---|---|
| 目的が自分の資金集めだった | 目的が支援。番組側の収益はゼロ |
| 名称が「ビアパーティ」だった | 告知の一行目に目的を置く。宴会に読める名前を使わない |
| 会費1万5千円が主催者に入った | **主催者は1円も受け取らない**設計にする |
| お笑い芸人の余興＝娯楽が主目的に見えた | 構成の主役は熊本の話。番組らしさは中盤以降 |
| 発災当日・1時間半後だった | 急性期を外す。時期そのものを企画の主張にする |
| 事後に釈明した（順序が逆） | 事前に趣旨と金の流れを公開、事後に総額と振込控えを公開 |
| 当事者が中にいなかった | 宮澤（家族が被災）、熊本ゆかりのゲスト、熊本ゆかりの店が主体 |

> なお「過剰な自粛は復興を妨げる」という論は、**判断根拠として内部で持つのはいいが、対外的には主張しない**。言えば言い訳に見える。実績で示すほうが強い。

## 3. 参考事例：個人・民間発 → 大きなうねりになったもの

### ふんばろう東日本支援プロジェクト（西條剛央）
東日本大震災を受けて、ボランティア経験のない研究者が個人で立ち上げ、日本最大級の支援組織になった。

- 被災者が「今ほしいもの」を必要な数だけサイトに掲載し、それを見た支援者が直接届ける仕組み
- Amazonの「ほしい物リスト」を活用し、24,000品目を扱った
- 小規模避難所・仮設住宅・個人避難宅など**3,000ヶ所以上**に、**155,000点**を**35,000件超**にわたって届けた
- 家電プロジェクトで25,000世帯に家電を配布。重機免許取得プロジェクトで200人超の有資格者を生んだ

**学び**: 募金を集めたのではなく、**仕組みを作った**。中間コストを取らない設計が規模を生んだ。

### #別府エール飯
コロナ禍で、大分県別府市の市民団体＋市が始めたテイクアウト応援キャンペーン。

- 「美味いは、コロナに負けない。持ち帰れ、別府の美味い飯。」
- 店側も客側も、料理の写真に `#別府エール飯` を付けてSNSに投稿するだけ
- 運営団体（ビービズ・リンク）が「`#○○エール飯` のコンセプトの使用許諾は不要」と明言してオープン化した
- 結果、全国の市区町村に `#○○エール飯` が波及した

**学び**: 真似しやすさ＝拡散力。**ブランドを独占しないことが拡散の条件だった。**

### アイス・バケツ・チャレンジ
- 2014年7月末〜8月末の約1ヶ月で、寄付金が約1億1,500万ドルに達した。日本ALS協会にも約3,900万円
- 拡散要因は、著名人の参加に加えて**指名制（バトン）・簡便性（バケツさえあれば誰でもできる）・目的の明確さ**がSNSの特性と噛み合ったこと
- ただし**寄付した人のリピート率は1%未満**。寄付者のほとんどが「それまで寄付したことのない人」だった

**学び**: 爆発力はあるが、**単発は一発で終わる**。この企画への警告として使う。

### Games Done Quick
- 2011年にメリーランド州で始まった小さなチャリティイベント。初回は$52,000
- 3年で$448,000に。以降、年2回の定期開催が続く
- 累計で**$59M超**を集め、うち$28M超をPrevent Cancer Foundationへ
- 2026年はAGDQで$2,443,414、SGDQで$2,408,701（国境なき医師団）。**54,000件超の寄付が80ヶ国以上から**

**学び**: コミュニティの「特技」（スピードラン）をそのまま寄付装置に変えた。そして**年2回の定期開催を続けたことで文化になった**。

### sinsai.info → Code for Japan / IT DART
- 関治之が東日本大震災の**発災4時間後**に震災情報収集サイト sinsai.info を立ち上げた
- 2013年10月に一般社団法人コード・フォー・ジャパンを設立、シビックテックへ
- IT DART（情報支援レスキュー隊）は、災害時に生まれる「情報の空白地帯」を埋めるためITのプロが設立した法人。発災100時間以内に緊急支援チームを派遣する

**学び**: 制度より先に動けるのは個人。ただし現地のニーズが読めないうちに手を出すと、善意が邪魔になる。

### 熊本地震2016の観光被害 ← 宮澤案の裏付け
- 九州全体で宿泊キャンセルが**75万人**に達した
- 2016年5月の宿泊者数：大分**-39.4%**、長崎**-30.7%**、鹿児島-20.5%、宮崎-18.8%。一方、熊本は**-10.6%**にとどまり、6月には**+13.2%**とプラスに転じた（復興関連の宿泊需要があったため）
- つまり**直接被害の小さかった周辺県のほうが、観光の落ち込みは大きかった**
- 「九州ふっこう割」が回復に効いた

**学び**: 災害の本当の被害は「壊れたもの」より**「行かなくなる・買わなくなる」**のほうが大きい。
→ 「熊本の人が東京に来たときにその店を使う」という宮澤案は、この逆流を作る発想として理にかなっている。

## 4. 自分たちの実力（正直な見立て）

| 項目 | 数字 |
|---|---|
| エピソード | 23本 |
| ショート候補 | 95本 |
| 直近10話の各話TOP合計 | 12,311再生 |
| 開始 | 2025年12月 |

コンセプトは「AIに勝てる、くだらなさを探せ。」ホストはミヤザワ(Voice)／ナカジマ(Muscle)／オモシュワくん(公式AI LINE BOT)。

**動員数では勝負にならない。** だから勝ち筋を3つに絞る。

1. **宮澤の「声」と熊本での信用** — 元KKTアナウンサー。しかも妻子が被災した一次体験がある。同情ではなく当事者として話せる
2. **中島のAI活用** — 少人数でも100件をさばける仕組みが作れる。ここが「巻き込み」の物理的な上限を外す
3. **毎週配信という定期接触装置** — 風化に抗える、この2人だけの武器

**最大の敵は金額ではなく風化。** 3ヶ月後に誰も言わなくなることが本当の損失。
一発の金額でNPOに勝とうとしない。「言い続ける」ことで勝つ。

## 5. アイデア一覧（8案）

「重さ」＝準備コスト、「寿命」＝続くかどうか。

### A. 熊本ナイト（東京・定期開催） ★第一弾の本命
東京で、熊本ゆかりの人が集まる会を定期開催する。参加費は飲食実費、寄付は別建て。

- **なぜおれらか**: 宮澤が場を回せる（元アナウンサー）。番組が告知装置になる
- **参考**: Games Done Quick（小さく始めて定期開催で文化にした）／アイスバケツ（単発は一発で終わるという反面教師）
- **重さ**: 中 ／ **寿命**: 長（定期化した場合）
- **鍵**: vol.1の当日に vol.2 の日付を告知すること。これをやるかどうかで寿命が決まる

### B. 熊本コール（音声リターン） ★第一弾に同梱
協賛してくれた人・店の名前と紹介を、宮澤がフルアナウンスで読む。音源データを納品し、店内BGM・SNS・電話保留音などに自由に使ってもらう。

- **なぜおれらか**: プロのアナウンス音声は、金では買いにくいのに原価がほぼゼロ。この非対称性が全て
- **参考**: ふんばろう（中間コストを取らない設計）
- **重さ**: 小（AIで原稿を量産すれば宮澤は読むだけ） ／ **寿命**: 中
- **鍵**: 原稿生成をAIに寄せること。ここを手作業にすると10件で破綻する

### C. 熊本ゆかり店マップ（東京） ★宮澤案の中核・企画の芯
協賛してくれた東京の熊本ゆかり店を、サイト上に恒常公開のマップ／リストとして残す。

- **なぜおれらか**: 番組サイト（omoshuwa-podcast.com）という置き場所を既に持っている
- **参考**: 熊本地震2016の観光データ（「行かなくなる」被害のほうが大きい）／別府エール飯（店と客をつなぐ）
- **重さ**: 中 ／ **寿命**: 長（資産として残る）
- **効く理由**:
  - 協賛の対価が単発で消えず資産として残る → **翌年も協賛してもらう理由になる**
  - 熊本の人が東京に来たときの実用ツールになる → 施しではなく縁になる
  - **「経済を回す活動」であることが、不謹慎批判に対する最も強い盾になる**

### D. 熊本ゆかり100人名鑑
首都圏にいる熊本出身・ゆかりの人を100人取材し、一人5分のPodcast／記事にする。

- **なぜおれらか**: AIで下調べ・質問設計・書き起こし・記事化を高速化できる。普通は100人は無理。**ここが「AIが使える」の本領**
- **参考**: ふんばろう（可視化された名簿がそのまま次の災害時の支援ネットワークになる）
- **重さ**: 大 ／ **寿命**: 長
- **注意**: 単体で始めると重すぎる。A・Cの副産物として育てるのが現実的

### E. 月1定期コーナー「熊本の今」 ★風化対策の本体
番組に月1の常設コーナーを作り、熊本の現状・現地の声を届け続ける。

- **なぜおれらか**: 毎週配信の枠を持っていること自体が資産。新しく何かを立ち上げなくていい
- **参考**: Games Done Quick（定期性が文化を作る）
- **重さ**: 小 ／ **寿命**: 最長
- **正直な評価**: **費用対効果は8案で最強。** イベントより地味だが、これが本丸

### F. #熊本のここ好き
熊本の好きな場所・思い出をハッシュタグで投稿してもらう。集まった投稿をAIで構成し、宮澤が朗読する音声にする。

- **なぜおれらか**: 「集める→構成する→読む」の3点セットが自分たちの形そのもの
- **参考**: 別府エール飯（**使用許諾不要でオープン化したから広がった**）／アイスバケツ（簡便性）
- **重さ**: 小 ／ **寿命**: 中
- **鍵**: 他の番組・コミュニティが勝手に真似できる形で公開すること。囲い込んだ瞬間に死ぬ

### G. 熊本DAY（7月28日）
毎年7月28日を「熊本のものを買う・熊本に寄付する・熊本をSNSで発信する」日として定着させる。

- **参考**: 別府エール飯（文化になった）／Games Done Quick（定期開催）
- **重さ**: 小（言い続けるだけ） ／ **寿命**: 最長
- **正直な評価**: 3〜5年かかる。ただし**今年から言い始めないと始まらない**ので、vol.1で種だけ蒔く

### H. AI × 情報支援（sinsai.info型）
被災地のニーズと支援をマッチングする仕組みを作る。

- **参考**: sinsai.info（発災4時間で立ち上げ）／IT DART
- **重さ**: 大 ／ **寿命**: —
- **判断: 今回はやらない。** 現地に入れず、ニーズの一次情報を持っていない状態でこれをやると、善意が邪魔になる。すでに公式の物資集積センターが稼働している。**この案は「やらないと決めた」ことを記録するために載せている**

## 6. 組み合わせの推奨

```
第一弾（9月以降）: A（熊本ナイト） + B（熊本コール） + C（店マップ）
      ↓ その場で
      G の種を蒔く（「来年の7月28日も、この話をしています」）
      ↓ 翌週から
常設:  E（月1コーナー「熊本の今」）← 本丸
      ↓ 余力が出たら
発展:  D（100人名鑑）、F（#熊本のここ好き）
除外:  H
```

**A・B・Cは3つで1セット。** バラすと弱くなる。
- A（場）がないとBの音声を披露する舞台がない
- B（音声）がないと協賛のリターンがない
- C（マップ）がないと協賛が単発で消えて、翌年につながらない

そして**Eをやらないなら、この企画はアイスバケツと同じ末路をたどる**。
